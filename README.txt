Site d'anniversaire - site statique (aucune compilation requise)

Déploiement sur Vercel :
1. Décompressez ce dossier.
2. Via Vercel CLI : lancez "vercel" dans le dossier, ou
   via le tableau de bord : New Project > importez le dossier (Framework Preset : Other).
3. Laissez Build Command et Output Directory vides.

Le prénom est défini dans index.html (variable PRENOM).
